# Predicting Diabetes Risk Using CDC Health Indicators

An end-to-end Machine Learning, Statistical Analysis, and Explainable AI (XAI) study using the **CDC BRFSS 2015** dataset.

## Study Questions & Objectives

1. **RQ1 (Statistical Association)**: Which demographic, lifestyle, and health-related factors are statistically associated with diabetes status in the BRFSS 2015 sample?
2. **RQ2 (Predictive Modeling & Screening)**: Which machine learning algorithm provides the most reliable prediction performance under class imbalance, and how does threshold tuning optimize recall for non-invasive screening?
3. **RQ3 (Explainability & Consistency)**: Are multivariate model explanations generated by SHAP statistically consistent with univariate effect-size evidence?

## Target Terminology Rules

- **Class 0**: `No reported diabetes` (`Without reported diabetes`, `no diabetes`).
- **Class 1**: `Prediabetes/diabetes positive class` (`Combined prediabetes/diabetes class`, `prediabetes or diabetes`).
- Do NOT use standalone terms like "Healthy" or "Diabetic" for target classes.

```bash
cd app && npm run prepare-data
```

## BRFSS Data Protocol & Study Scope Limitations

- **Self-Reported Data**: The CDC Behavioral Risk Factor Surveillance System (BRFSS) relies on self-reported telephone survey responses rather than direct clinical diagnostic tests (e.g., HbA1c or fasting plasma glucose).
- **Repeated Profiles**: 24,206 repeated feature profiles exist in the cleaned dataset (N = 253,680). Because BRFSS is an anonymous population survey lacking individual respondent IDs, these identical feature combinations represent legitimate distinct respondents and are strictly retained to preserve natural sampling prevalence.
- **Causality Disclaimer**: All statistical and machine learning findings represent sample-level marginal associations and predictive feature contributions. They do not constitute clinical causation or population-level causal claims.
